# 独立意味判定ルーブリック v1

判定単位は提示された議題・会議フェーズ・発話列の観測末尾。id以外の生成メタデータ、設計意図、作者の理由、他者ラベル、Jev予測は評価者に渡さない。連続スコアや現行閾値は使わない。

- INTERVENE_DRIFT: 現在合意した議題・段階から無益な別話題が持続し、末尾でも復帰していない。
- INTERVENE_STALLED: 同じ主張、未解決の問い・障害が反復し、情報、選択肢、判断基準、決定、次の一歩が増えていない。
- OK: 有益な寄道、根拠の増える対立、情報整理、合意された発散、許可休憩・思考時間、末尾までに復帰した話題等。決定未了や準備中だけでは介入対象にしない。

両方が独立に介入を要する場合のみSTALLED優先。単なる脱線を自動的に停滞にもしない。時刻情報なしに沈黙時間を推測せず、未来の復帰も推測しない。短い冗談や言い直し、一度の確認だけで介入としない。局所の具体的利益・新情報・比較・合意・次の手順を読む。

出力はid,status,reason（日本語で会話固有の根拠）,evidenceTurns（0始まり）,confidence(high/medium/low),uncertain(bool),alternativeStatus(null可),annotator,labelSource=independent_gpt_silver,humanReviewed=false。gold.actionは出さない。判定不能・境界は隠さず不確実と記録。設計意図へ合わせる義務はない。GPT同士の判断であり人間goldや完全に独立な基盤モデルではない。
