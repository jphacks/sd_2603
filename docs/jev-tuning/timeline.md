# Jevチューニングの全作業

2026年10月17日夜〜18日。データ担当・評価担当・staging統合担当の作業を時系列で整理。

1. **方針決定** — 再学習ではなく、判定基準・Prompt・閾値を最適化。
2. **資料調査** — 論文・AMI/AMI-MEなどの会話資料を調査。出典・ライセンスを記録。
3. **基準作成** — 3パラメータ各32項目、反例・スコア基準を定義。
4. **初期データ作成** — 実録100窓・日本語合成36件を用意。独立ラベル・再判定・漏洩監査を実施。
5. **評価基盤実装** — Gateway実行、スコア保存、閾値探索、混同行列、Markdownログを自動化。
6. **少量実測** — 最初の10件で応答速度を確認。費用を予約管理し、保存スコアを再利用。
7. **初期探索** — 質問3種×閾値216組を比較。実録Testは探索候補17/20、表示制約に沿う採用候補14/20。
8. **合成データ拡充** — Pro担当と分担し、日本語100系列・500件を作成。独立GPTラベルと出典を監査。
9. **過学習対策** — 系列単位でTrain300／Validation100／Test100に固定。Train内で5分割交差検証。
10. **設定選択** — Prompt v4を選択。閾値を脱線0.6→0.5、停滞0.6維持、有用性0.6→0.8へ変更。
11. **未使用Test評価** — Validationで固定後に実測。合成Testはv3・v4とも100/100。
12. **PR #35追加評価** — 台本text169件を独立ラベル付け→別エージェントでテスト。v3は159/169、v4は162/169。
13. **更新ラベル比較** — PR #35を再取得。固定済み独立ラベルとの一致率は比較可能92件中91件。
14. **最新staging統合** — Node24改修を取り込み、4質問目interveneNow・介入ゲート・名称を維持。
15. **統合版再実測** — 4質問版v4-staging-gatedは163/169（96.45%）。モデルをjev-1.14.0へ固定。
16. **回帰確認** — 全171テスト、Lint、型、ビルド、会議7ケース、スモークを確認。表示の閾値も設定と共通化。
17. **staging反映** — 05573caをPush・デプロイ。公開APIでモデル・質問版・4スコアを確認。復旧タグを保存。
18. **PR整理** — #45に反映記録と本一覧を追加。Production向けの誤った#44はクローズ。Production反映は未実施。

**現在のstaging：** Jev `1.14.0`／`v4-staging-gated`／閾値 `0.5・0.6・0.8`。実装はすでに反映済みのため、本PRの追加差分はドキュメント。

**数字の範囲：** GPT参照ラベルとの一致率。実会議・人間goldでの精度ではない。合成Test上のv3→v4改善差は未確認。1,000件は未完成のため500件で固定。
