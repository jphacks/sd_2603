## ゴール

テーマ: 会議を脱線させないファシリテーター

- 解決する課題
  - 会議は気づくと議題から外れたり、同じ話を繰り返したりする。話を戻す役は誰もやりたがらないし、遠慮して言い出しにくい。AI が逐一口を挟むと、うるさくて誰も使わなくなる。
- アイデア
  - アジェンダと会話を聞きながら、「議題から脱線していないか」「議論が止まっていないか」「今声をかける価値があるか」を AI が判断する。本当に必要なときだけ、発言の切れ目で「そろそろ〇〇の結論に戻りませんか」と短く一言かける。必要なければ何もしない。
  - 売りは話を戻すことではなく、いつ口を出して、いつ何もしないかの判断。意味のある寄り道まで止めたり、発言中に割り込んだりすると逆効果になる。
  - 人間が気づいたときにボタン押下などで、代わりに突っ込んでくれる機能もあっていいかも。
- 技術
  - Jev（TypeSafe AI）で SILENCE / WAIT / INTERVENE を判定する。
  - 声かけは、あらかじめ用意した短い一言をブラウザの音声合成（Web Speech Synthesis）で読み上げる。吹き出し表示でもよい。
  - 構成は Next.js ＋ Vercel AI Gateway。
- 進め方
  - Hack Day（10/17〜18）: 脱線・停滞の判断ロジック、声をかけるタイミングの制御（発言の切れ目を待つ、一度声をかけたらしばらく控える、AI 自身の声を拾わない）、デモ。
  - 余裕があれば M5StickS3 のスピーカーから声をかけ、画面に状態を表示する。
  - 都度、その機能が本当に必要かを考えながら実装する。

| 決めること | 内容 |
| --- | --- |
| 誰が使うか | 会議で議論の停滞に困っている人 |
| どんな困りごとか | 脱線に気づいても話を遮って戻しづらい。沈黙が続いて議論が進まない。アジェンダが終わっているのに、なんとなくの会話で会議が終わらない |
| どう解決するか | 第三者として会議の進行を手助けするエージェントを参加させる。従来の UI ではなく、察して動くエージェントにして、特定の参加者に責任や負荷をかけない（Zero-UI）。Jev を使う |
| 提供する価値 | 会議を思い通りにコントロールできる。負担やストレスなく、狙った意思決定のために議論をコントロールできる。会議の温度感・カジュアル度を調整しやすくなる |
| デモで見せる動作 | 脱線して誰も戻そうとしない場面で「●●の議論に戻りませんか？」と提案する。沈黙が続いたときに、議論を進める一言を挟む |
| 見せ終わって伝えたいこと | 「自動で話す AI」ではなく、介入するタイミングを判断する AI。「察してくれる AI」 |

## メンターからの反応

- Zero-UI のコンセプトは、課題と解決したいことが書いてあればよい。共感性も高い。
- ピッチは、話す内容の整理と練習。
- デモは、実際に動いているものを見せる。裏の挙動も見えるとわかりやすい。
- アーキテクチャの実現可能性は問題なし。
- 人が増えてカメラが小さくなる問題は、サービスによって変わる。エフェクト、通知、挙手、音、リアクションで補う。
- アジェンダは、チャットにファイルを送る案に加え、Bot をメンションする。
- 脱線判定に加え、アジェンダから逆算して間に合わなそうならアラートする、は optional。
- GitHub の評価は README などのドキュメントが中心。動いていることが大事。コードの中身は細かく見ない可能性が高い。基本はプレゼン録画と、動作がわかる GitHub 上の動画。
- パラメータの選定も伝わるようにする。
- スピーカー付きデバイスも借りられる。[M5Stack Cardputer](https://docs.m5stack.com/ja/core/Cardputer)
