## 日本語合成会議500件でのJev評価（2026-10-18）

多様な会議シナリオ100系列・500件をAIで作成し、作者とは別担当のGPTによるsilverラベルを付けました。同じ系列を分割せずTrain300/Validation100/Test100に固定し、Trainのみの5分割交差検証、Prompt・閾値探索、Validationでの設定固定後に未使用Testを実測しています。

| 設定 | Validation一致率 | 未使用Test一致率 |
| --- | ---: | ---: |
| 現行v3・閾値0.6/0.6/0.6 | 99/100（99%） | 100/100（100%） |
| 選択v4・閾値0.5/0.6/0.8 | 100/100（100%） | 100/100（100%） |

**今回の合成Testで80%目標を達成しました。実会議・人間goldでの精度ではありません。** Testは脱線30・停滞30・OK40（多数派のみなら40%）、Macro-F1は両設定1.000。現行設定も全問正解で、Test上の改善差は確認できていません。1,000件は未完成のため、11:00時点の監査済み500件へ固定しました。

画面の60%/40%表示を維持する事前ルールに従い、異なる閾値の選択設定は実験JSONへ保存し、アプリ既定値は現行v3を維持しています。状態名・画面・介入文言は変更していません。探索とCVはスコアを再利用し、新規Gatewayは1,401試行・1,400成功。公開入力単価だけの見積もり約$0.078、保守的予約$1.558（請求総額は未測定）です。

## 旧実録コーパスでの評価（同日・別実験）

公開会議コーパスの実録100件と、日本語の合成訓練例36件を用意しました。会議系列単位で分割し、独立したGPTラベル、3種類の質問、648通りの閾値設定を比較しています。Testは設定固定後に採点し、探索では保存済みスコアを再利用しました。

| 設定 | ValidationのLLMラベル一致 | 未使用TestのLLMラベル一致 |
| --- | ---: | ---: |
| 従来の質問・閾値 | 12/20（60%） | 13/20（65%） |
| 探索で選んだ質問v2・閾値0.8/0.7/0.6 | 18/20（90%） | 17/20（85%） |
| アプリ採用：質問v3・元の閾値を維持 | 15/20（75%） | 14/20（70%） |

**85%は人間が確認した精度や本番精度ではありません。** TestはOK19件・停滞1件・脱線0件で、常にOKなら95%です。停滞の正例も見逃しており、この結果で「介入精度80%を達成」とは主張しません。名称・画面表示を維持するため、アプリには事前に選んだPrompt改善のみを反映し、探索した閾値は実験結果として保存しています。
