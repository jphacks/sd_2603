# Jev の介入判定評価

`jev-cases.json` は、モデルの結果を見る前に期待アクションを付けた日本語の模擬会議ケース集です。同じ議論の短い時点と長い時点を含め、話題の逸脱、進展、意味のある寄り道、停滞、クールダウン、短すぎる会話、軽い文字起こしノイズを確認します。これは実会議から採取したデータではありません。

実行には Node.js と依存パッケージが必要です。

```powershell
node evals/run-jev.mjs
node --env-file=.env.local evals/run-jev.mjs --live
```

`--live` は Vercel AI Gateway に有料リクエストを送ります。`--limit=5` で先頭 5 ケースまでに制限できます。認証情報、入力全文、レスポンス本文は保存しません。標準出力にケース ID、期待値、判定値、診断スコア、集計を JSON で出します。

## 2026-10-17 の結果

- 20 ケース中 18 件が Gateway を呼び、2 件はアプリ側のクールダウン・発言数不足で呼びませんでした。API エラー 0 件。
- アクション完全一致は 18/20（90%）。介入の適合率は 5/7（71%）、再現率は 5/5（100%）。意味のある寄り道への介入は 0/4。
- 早い介入が 2 件。`release-drift-1` は短い脱線の開始直後に drifted=0.96 で介入し、`budget-stall-1` は最初の意見対立で stalled=0.85 と判定して介入しました。どちらも人手ラベルは `WAIT` です。長く続いた対になるケースでは介入が適切でした。
- Gateway 呼び出し 18 件の応答時間は中央値 284 ms、95 パーセンタイル 829 ms。この測定に音声認識・会議転送の遅延は含みません。

混同行列（行: 人手ラベル、列: 実際の判定）:

|  | SILENCE | WAIT | INTERVENE |
| --- | ---: | ---: | ---: |
| SILENCE | 12 | 0 | 0 |
| WAIT | 0 | 1 | 2 |
| INTERVENE | 0 | 0 | 5 |

この少数・合成データにおける値は本番精度の推定ではありません。特に介入の適合率 5/7 は分母が小さく、実会議の脱線頻度や発話の長さを反映していません。ケースを見て閾値を最適化すると過学習するため、現行閾値はこの結果だけでは変更していません。

## 判定できない安全条件と次の検証

現在の `JudgeInput` はアジェンダ、発言文字列、前回介入からの秒数だけです。発話中か、発言の切れ目か、寄り道が何秒続いたか、参加者が自然に議題へ戻ったかを表せません。したがって、この評価は「何を話しているか」の判定であり、「いつ割り込んでよいか」の評価ではありません。

次は匿名化した実会議の時系列を人手でラベル付けし、短い脱線・議論の対立が自然解消するまでの時間を測ります。介入提案は発話の切れ目まで保留し、その間に会話が戻れば破棄する設計を検証します。精度は介入適合率に加え、会議 1 時間当たりの不要な介入、見逃し、介入までの遅延で測るべきです。
